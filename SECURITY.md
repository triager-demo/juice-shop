# Security

Security reviews should assess the application code, dependencies, configuration,
and deployed infrastructure. Record findings with the affected component,
reproduction steps, impact, and proposed remediation. Do not include credentials
or customer data in reports.

This repository is maintained separately from upstream OWASP Juice Shop. Its
release history and support commitments do not establish support guarantees for
this deployment.

Coordinate disclosure of sensitive findings privately with the repository owner
before publishing reproduction details.
